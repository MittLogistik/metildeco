# Betalsätts-logotyper

Används enbart för att visa vilka betalsätt butiken tar emot (nominativ användning enligt respektive varumärkes riktlinjer).

- visa.svg, mastercard.svg, amex.svg – från paketet payment-icons (MPL-2.0), se LICENSE-payment-icons.txt.
- klarna.svg – Klarnas officiella "Payment Badge" från x.klarnacdn.net.
- applepay.svg, googlepay.svg – Simple Icons (CC0).
- swish.svg – Swish-logotyp (varumärke tillhör Getswish AB), vektor via Wikipedia.
